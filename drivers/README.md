# Drivers

X6886 kernel drivers grouped by subsystem:

| Directory | Contents |
|---|---|
| `audio/` | Audio driver |
| `bluetooth/` | Bluetooth driver |
| `camera/` | Camera driver |
| `core/` | Keys and USB |
| `gpu/` | Mali-G57 Valhall v9 driver |
| `input/` | Touch driver |
| `modem/` | Cellular driver |
| `power/` | Battery and charger drivers |
| `wifi/` | Wi-Fi driver |

Detailed reviews live in [docs/driver-review](../docs/driver-review/).
